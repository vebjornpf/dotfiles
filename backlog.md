# Dotfiles Backlog

## Rules
- One item per bullet
- Start each item with `- [ ]`
- Keep each item on one line
- Format: `- [ ] <area>: <task>` or `- [ ] <area>: <task> (`backlog/<slug>.md`)`
- Use short imperative wording
- Link a detail file when the task needs findings, notes, or a plan
- Remove the item when the work is complete
