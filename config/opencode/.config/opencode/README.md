# OpenCode

Terminal preferences live in `cli.json`. The selected custom theme,
`themes/catppuccin-frappe-transparent.json`, uses the V2 theme format with
Catppuccin Frappé colors.

The main view, panels, and prompt input use transparent backgrounds so iTerm's
background shows through. Menus/dialogs remain opaque for readability; diff
additions/removals and focused selections retain color highlights.

Use `/reload` after changing the theme, then select it with `/themes` if needed.
